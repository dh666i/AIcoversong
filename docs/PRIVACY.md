# 本地数据与隐私 / Local data and privacy

AIcoversong 的翻唱流程在你的电脑上运行。默认网页监听 `127.0.0.1`；不需要账户、API Key 或云端推理服务。

| 目录 | 内容 |
|---|---|
| `recordings/` | 自己保存的录音与稿件元数据 |
| `songs/` | 你自行放入的歌曲（如有） |
| `output/` | 每次翻唱的源文件副本、分离轨、结果与任务记录 |
| `Applio/logs/MyVoice*/` | 训练切片、特征、个人音色与索引 |
| `logs/` | 应用/训练日志，可能含本机路径、文件名 |
| `cache/` | 浏览器上传副本、模型缓存及临时文件 |
| `Applio/assets/config.json` | 本机配置 |

以上数据不应提交到 GitHub。`.gitignore` 和 `tools/verify_package.py` 提供误提交检查，但无法证明所有文件均不含私人信息；提交问题或截图前仍需查看内容。

安装模型和依赖需要联网，并向相应上游服务发送常规下载请求。完成安装后，正常本地翻唱不需要上传歌曲到外部服务。使用完整上游 Applio 页面、可选更新或自行启用其他插件，可能产生额外网络请求；那不属于此处对本地默认翻唱流程的描述。

历史作品不会自动上传或公开。删除本地源文件、模型和录音前自行备份。浏览器刷新不应当被当成删除数据的方法。
